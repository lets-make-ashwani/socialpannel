# 👑 Social Panel — Master Fleet Control Center

Unified cloud orchestration panel for all your autonomous social media bots (Gadgets Mankind, Stylish Girl Dress, Anime Find, and more). Built with FastAPI, Tailwind CSS, and Vercel Geist design aesthetics, designed to run 24/7 on **Render.com**.

---

## ⚡ Features
* **Global KPI Overview**: Real-time metrics across all automation bots, post counts, and API health.
* **Autonomous Bot Fleet Cards**: Monitor status (24/7 Active / Standby), source channels, AI dubbing models, and next post schedules.
* **1-Click Cycle Trigger**: Run on-demand automation cycles from any device via web interface.
* **Unified Live Activity Feed**: Chronological stream of posts across Instagram Reels, Facebook Pages, and Threads with direct live links.
* **Production Docker & Render Blueprint**: Ready for 1-click cloud deployment with `Dockerfile` and `render.yaml`.

---

## 🚀 Cloud Deployment on Render.com
1. Go to **[dashboard.render.com](https://dashboard.render.com/)** ➔ **New +** ➔ **Web Service**.
2. Connect your repository: `https://github.com/lets-make-ashwani/socialpannel.git`.
3. Select **Docker** environment.
4. Click **Deploy Web Service**!
